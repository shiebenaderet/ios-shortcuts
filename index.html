How View Archived works

Share any page from Safari (or copy a link and run the shortcut) and it opens archive.ph/newest/ plus your URL — the most recent snapshot of that page. If no snapshot exists yet, archive.today offers to save one on the spot.

Installing

Everything installs through iCloud links because iOS only accepts signed shortcuts. After adding one, find it in Safari’s share sheet — drag it into Favorites (share sheet → Edit Actions) so it sits at the top.

Rebuild instructions for every shortcut live in the repo README.
